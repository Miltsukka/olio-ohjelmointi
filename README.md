# Olio-ohjelmointi

C++-harjoitustehtävät Qt Creatorilla.

Harjoitukset tallennetaan omiin alikansioihinsa (`h1`, `h2a`, `h2b` jne.) tehtävänannon mukaisesti.

## Palauttaminen

```bash
git add .
git commit -m "tehtävä 1 valmis"
git push origin main
```

## Git-asetukset

`.gitignore` ohittaa projektien build-kansiot ja Qt Creatorin `.user`-asetustiedostot.
